- **025 adds a publish step**: `schemalane-version` must publish before macros/core/cli (release.yml ordering — plan 025 Step 5; coordinate with plan 015's publish loop).
- Spikes produce designs in `plans/designs/`, not code on main.

## Findings considered and rejected (do not re-audit)

- **Checksum lone-`\r` / BOM deviation from Flyway** — documented tradeoff (SCHEMALANE_SPEC.md §6.3 + doc comment on `calculate_checksum`); revisit only if full byte parity is ever promised.
- **`cargo run` delegation rebuild latency** — spec'd execution model (§2.2); any change is a product design decision, not a fix.
- **`offset_to_line` "wild pointer arithmetic" claim** (one audit agent) — REFUTED: pg_query 6.1.1 `split_with_parser` returns `&query[start..end]` sub-slices of the input (verified in crate source); the pointer math is sound. The related off-by-whitespace issue IS real → plan 011 (D).
- **`postgres://chainargos:secret@localhost` strings in tests** — fixture placeholders, not credentials; no rotation needed.
- **`--all-features` in CI is a no-op** (no crate declares features) — harmless; tidy opportunistically in plan 015, not worth its own plan.
- **`embed_migrations!` path traversal / symlink follow** — macro argument is authored by the compiling developer (self-directed); LOW severity; not planned.
- **Lockfile duplicate majors in the dev tree** (testcontainers stack; `thiserror` 1.x forced by pg_query at runtime) — upstream-bound, build-time-only cost; tracked in plan 016's maintenance notes.
- **Observer event-struct consolidation** (six ~identical structs) — public-API churn for aesthetics; deferred to a future breaking release (noted in plan 028).
- **Formatter deep-recursion stack overflow** — pathological inputs only, operator-authored files; guard sketched in plan 035 maintenance notes, not planned.
- **`#![allow(clippy::future_not_send)]` breadth** — investigate-only; noted in plan 027 maintenance notes.
- **MySQL/SQLite, down/undo, repeatable/baseline migrations** — explicitly out of scope per spec §1.2; direction spikes deliberately avoid them.
